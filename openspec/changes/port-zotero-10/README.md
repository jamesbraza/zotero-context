# port-zotero-10

Port Zotero Context to Zotero 10 (Zotero-10-only): rebuild sentence snap on Zotero 10's Structured Document Text (SDT) after Zotero 10 removed the Read Aloud segment API the plugin relied on, and adopt the Zotero 10 capabilities that are clear wins (offscreen region rendering, SDT section locators, SDT element picking, SDT fulltext over MCP, Quick Copy citations).
