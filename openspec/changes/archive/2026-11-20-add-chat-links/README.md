# add-chat-links

Link AI chats (claude.ai, Claude desktop, Claude Code, Codex, any chat URL) to the Zotero papers they discussed, as child notes, for posterity rather than citation. Starting a chat from Zotero (paper intro or the New chat button) links it automatically where the chat tool allows: Claude Code via a Zotero-minted session ID, and claude.ai hosted in a reader side pane. Gates the v0.1.0 tag alongside `add-context-ferry`.
